# Autocomplete and Autocorrect Data Analytics

## Objective
Analyze text patterns and build simple autocomplete and autocorrect systems using Natural Language Processing techniques.

## Dataset
Gutenberg English text corpus was used as the text corpus for NLP analysis.

## Steps Performed
- Text preprocessing
- Lowercasing
- Tokenization
- Punctuation removal
- Stopword removal
- Bigram model creation
- Trigram model creation
- Autocomplete testing with multiple prefixes
- Levenshtein edit distance
- Autocorrect implementation
- Testing with 20 misspelled words
- Accuracy evaluation
- Precision and Recall evaluation
- Top 20 word frequency analysis
- Confusion matrix analysis
- Bigram and Trigram comparison

## Technologies Used
- Python
- Pandas
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Conclusion
The project demonstrates how NLP techniques can be used to build basic autocomplete and autocorrect systems. Bigram and trigram models were used for next-word prediction, while Levenshtein edit distance was used for spelling correction.
