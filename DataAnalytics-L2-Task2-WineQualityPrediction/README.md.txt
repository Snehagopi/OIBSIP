# Wine Quality Prediction

## Objective
Predict wine quality using machine learning classification models based on physicochemical properties.

## Dataset
Wine Quality dataset containing physicochemical measurements of red wine and quality scores.

## Steps Performed
- Data loading and inspection
- Exploratory Data Analysis
- Quality score distribution analysis
- Correlation heatmap
- Class imbalance analysis
- Stratified train-test split
- Random Forest classification
- SGD classification
- SVC classification
- Confusion matrix
- Random Forest feature importance
- Model accuracy comparison
- Quality grouping into Poor, Average, and Good classes

## Models Used
- Random Forest
- SGD Classifier
- Support Vector Classifier (SVC)

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Conclusion
Machine learning classification models were used to predict wine quality from physicochemical properties. The original quality scores were also grouped into three classes: Poor, Average, and Good, to simplify the classification problem.
