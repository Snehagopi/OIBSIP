# House Price Prediction

## Objective
Predict house sale prices using Linear Regression.

## Dataset
Ames Housing dataset from Kaggle House Prices - Advanced Regression Techniques.

## Steps Performed
- Exploratory Data Analysis
- Missing value handling
- Categorical variable encoding
- Correlation analysis
- Train-test split
- Linear Regression model
- Model evaluation using MSE, RMSE, and R²
- Actual vs Predicted price visualization
- Residual analysis
- Feature coefficient analysis

## Model
Linear Regression

## Evaluation Metrics
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Conclusion
The Linear Regression model was used to predict house sale prices based on available housing features. The analysis demonstrates how machine learning can be applied to estimate house prices and understand the influence of different features.
