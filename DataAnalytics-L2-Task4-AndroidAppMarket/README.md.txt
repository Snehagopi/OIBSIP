# Android App Market Analysis

## Objective
Analyze the Google Play Store app market to understand app categories, ratings, installs, pricing, and user sentiment.

## Dataset
Google Play Store Apps dataset containing app information and user reviews.

## Steps Performed
- Data loading and inspection
- Missing value analysis
- Duplicate removal
- Data cleaning
- App category analysis
- Rating distribution analysis
- Average rating by category
- App size vs installs analysis
- Free vs paid app analysis
- Paid app price analysis
- Estimated revenue analysis
- User review sentiment analysis using TextBlob
- Sentiment analysis by app category

## Sentiment Analysis
TextBlob was used to calculate review polarity and classify reviews as:
- Positive
- Negative
- Neutral

## Conclusion
The Google Play Store dataset was analyzed to understand app categories, ratings, installs, pricing, and user sentiment. The analysis provides insights into app popularity, user satisfaction, pricing patterns, and sentiment across different app categories.
